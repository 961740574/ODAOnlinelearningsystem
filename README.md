# ODA BULTUM UNIVERSITY

## ONLINE LEARNING AND TEACHING SYSTEM

This project is a web-based Online Learning and Teaching System developed for ODA Bultum University.

### Main Features

#### Student Module
- Student Registration
- Student Login and Logout
- Student Dashboard
- View and Update Student Profile
- View Available Courses
- Course Enrollment
- View Enrolled Courses
- View Assignments
- Submit Assignments
- Join Live Classes
- Take Online Exams
- View Exam Results
- View Grades

#### Teacher Module
- Teacher Registration
- Teacher Login and Logout
- Teacher Dashboard
- Manage Courses
- Add New Courses
- View Courses
- Create Assignments
- View Student Submissions
- Grade Student Assignments
- Manage Exams
- Add Exam Questions
- View Student Exam Results

#### System Features
- Database Connectivity
- Student and Teacher Authentication
- Session Management
- Course Management
- Assignment Management
- Examination and Result Management

### Technologies Used
- Java
- HTML and CSS
- MySQL
- Apache Tomcat
- NetBeans IDE
- Maven
